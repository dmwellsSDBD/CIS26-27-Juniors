Font Properties

Generic families

Serif: small strokes at the ends of letters (Georgia, Times New Roman)

Sans-serif: plain stroke ends (Arial, Helvetica, Verdana)

Cursive: handwriting style (Brush Script MT, Comic Sans MS)

Fantasy: decorative (Impact)

Monospace: every character is the same width (Courier New)

Weight, style, variant

font-weight: bold

font-style: italic

font-variant: small-caps (after you finish Try It b)

The font shorthand

font: italic small-caps bold 1.4rem Georgia, serif;
