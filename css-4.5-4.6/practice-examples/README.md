# Practice Examples: zyBooks 4.5 and 4.6

Open each file in a browser and in VS Code side by side. Every file has a **TRY IT** list in the comment at the top. Make one change, save, and refresh the browser.

| File | Topic | zyBooks |
|---|---|---|
| `01-color-values.html` | Color names, RGB, hex, HSL, RGBA, HSLA | 4.5 |
| `02-backgrounds.html` | `background-color`, `background-image`, `background` | 4.5 |
| `03-float-clear.html` | `float` and `clear` | 4.5 |
| `04-display.html` | `inline`, `block`, `none`, `inline-block`, `list-item` | 4.5 |
| `05-css-variables.html` | `:root`, `--name`, `var()` | 4.5 |
| `06-font-properties.html` | `font-family`, weight, style, variant, `font` shorthand | 4.6 |
| `07-font-sizes.html` | Size names, absolute and relative units | 4.6 |
| `08-text-properties.html` | `text-align`, `text-decoration`, `text-transform`, `text-indent` | 4.6 |

These files use a `<style>` block so each example fits in one file. Your projects still use an **external** stylesheet.
