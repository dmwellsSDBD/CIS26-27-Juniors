HTML Lists

There are 3 types of HTML Lists

Unordered Lists

Unordered lists are lists that have bullert points to the left of each list item. These lists are contained in a <ul> tag. Each item in the list is contained in an <li> tag.

  • Cedric
  • Ian
  • Alex
  • Levi
  • Martin
  • Angus
  • Kaleb

NOTE: Unordered lists are the base HTML structure used to create navigation.

Ordered Lists

Ordered lists are used to create a sequence of items or steps. These list items have a number, roman numerals, or alpha character to the left of each item. Like <ul> items, ordered list items are contained in <li>.

  1. Step 1: crack eggs
  2. Step 2: add milk
  3. Step 3: whisk eggs and milk
  4. Step 4: pour into a hot pan
  5. Step 5: stir until done

Anchor-tags

Anchor element defines a hyperlink in a webpage. A hyperlink, or link, specifies where other information is located and what action the web browser should perform when a user clicks the hyperlink.

Absolute and Relative URLs

URL: Universal Resource Locator - otherwise known as a web address.

Absolute URLs: - This is a COMPLETE URL including the transfer protocol. Example:
https://resources.zybooks.com/WebProgramming/mediumCatv1.jpg

Relative URLs: - This specifies a "relative" path to the web resource with no scheme or hostname (protocl or domain). They refer to resources based on the current web address you are in.

An example it the link to the index.html file at the top of this section.

Section Links

A URL can point to a section, or FRAGMENT, of a document by adding a hash tag (#) and a fragment identifier at the end or the URL.

EX:
https://en.wikipedia.org/wiki/Computer_science#History

The section listed after the # refers to an ID attribute. EX:
<section id="History"> - what the id attribute creates is called a fragment identifier.
