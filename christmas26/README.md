# Christmas 2026 Wishlist: Teacher Sample

Plain HTML and CSS rebuild of the 2024 Tailwind wishlist site. Upload the
whole `christmas` folder to a GitHub repository to publish it with GitHub Pages.

- `index.html`: landing page with 9 cards
- `item-template.html`: the pattern students copy (CAPITALS placeholders)
- `item1.html` to `item9.html`: finished item pages
- `css/styles.css`: one stylesheet, sections labeled by project phase
- `js/script.js`: extra credit only (phone menu toggle)

Notes:
- The item photos in `img/items` are generated placeholders. Swap in your own
  photos with the same file names.
- Prices for items 2 to 5 are examples, not looked-up prices.
- Header photo and street lamp / candle photos are from Unsplash (credits in
  the starter kit's PHOTO-CREDITS.txt).
